01A model you can question

From formal model
to clear answers.

Petri nets describe systems where events compete for resources, happen in parallel, or wait on one another. RACoN gives students, researchers, and engineers a practical way to reason about those systems: load a model, inspect its structure, explore possible states, and check whether the behavior meets a formal property.

Built for discrete-event systems, workflows, protocols, and any process where “what can happen next?” matters.

UNDERSTAND

Read the structure

Inspect places, transitions, arcs, incidence matrices, structural properties, and invariants.

EXPLORE

Trace what can happen

Build reachability graphs or coverability results, then follow paths and inspect markings.

✓

VERIFY

Check a property

Evaluate CTL formulas and bad-state queries, with witnesses or counterexamples when available.

02A practical workflow

Bring a model.
Follow the behavior.

RACoN keeps the path from input to result visible and interactive.

A

Load your net

Open an INA/PNT `.pnt` file or paste a compatible Mercury script. RACoN validates the model before analysis.

↘
B

Choose a question

Start with structural properties, calculate invariants, generate a state space, or define a CTL or bad-state check.

↘
C

Explore the result

Inspect graphs, markings, paths, evidence, and algorithm limits. Use the token game to step through enabled transitions.
